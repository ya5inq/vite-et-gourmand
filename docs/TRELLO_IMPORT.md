# Import rapide Trello — coller par colonne

**Comment faire (par colonne) :**
1. Dans Trello, sous la liste, clique **« + Ajouter une carte »**.
2. **Copie tout le bloc** de titres ci-dessous (entre les lignes) et **colle-le**.
3. Trello détecte plusieurs lignes → **« Créer N cartes »** → valide.
4. Répète pour chaque liste.

> Les titres seuls sont créés. Descriptions détaillées : voir
> `docs/TRELLO_BOARD.md` (à recopier dans les cartes si besoin).
